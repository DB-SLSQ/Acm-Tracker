## ACM 训练台 v1.0.4

这一版加了一个新页面「我的题单」，另外把「历年比赛」里做过和没做过的题重新分了形。

### 下载

下载下方的 `ACM Trainer Setup 1.0.4.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 历年比赛：做过 / 没做过重新分了形

以前只是把做过的题压暗，整页都是彩色小块，扫起来累眼睛。现在两种形态分开：

- **没做过** = 实心难度色块 + 难度数字（要做的题才显眼）
- **做过** = 空心虚线框 + `✓` + 灰字删节线，连难度数字都不显示（鼠标停上去还能看到）

每场比赛的左边多了一条状态色：**没动过**是亮蓝色边、「做过一部分」是灰边、**已经打完**的整张卡压暗。
进度文字也跟着变：`还没动过` / `做过 3/7` / `已打完 7 题`——不用一行行看色块就知道哪场值得打。

### 新页面：我的题单

左边菜单新增「我的题单」（在「拼好题」下面）。攒下来的题有地方放了：

- **贴一段文本就成题单**：题号、题目链接都行。认得 `2173A`（Codeforces）、`ABC476D`（AtCoder，
  补零不补零都认）、`P2120`（洛谷），以及各自站点的题目链接；对不上的题号会单独列出来告诉你
  （比如题库里还没有的新题），不会闷声丢掉。
- **「拼好题」一键存**：拼完那一套点「存成题单」直接进来，不用先复制再粘贴。
- 存下来之后**逐题勾进度**，顶部下拉里一眼看到每张题单的 `做完/总数`，
  左侧菜单里也能看到。还能「追加题目」「移除某道」「删除整个题单」「复制没做完的」。
- 题单存在本机数据库里（`problem_lists` / `problem_list_items` 两张表），和训练计划互不影响——
  删题单不会动题库、不会动计划。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
