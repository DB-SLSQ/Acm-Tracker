## ACM 训练台 v1.0.15

这一版两件大事：**修掉一个多账号串号的 bug**，以及**开始支持 Linux**。

### 下载

**Windows**：下载下方的 `ACM Trainer Setup 1.0.15.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

**Linux（Ubuntu / Debian 等）**：

- `.AppImage`：下载后 `chmod +x ACM.Trainer-1.0.15.AppImage`，直接双击/命令行运行；
- `.deb`：`sudo dpkg -i ACM.Trainer-1.0.15.deb` 安装，装完在应用菜单里找 ACM Trainer。

Linux 版数据保存在 `~/.config/ACM Trainer/data/`。要求 glibc 较新的发行版（Ubuntu 22.04 及以后没问题）。

### 修复：多账号切换时平台账号串号

有群友反馈：先填自己的 CF id 加载，再填队员的 CF id、给队员配了 AtCoder 账号并点同步，
切回自己的 CF id 后，平台卡片显示的却是队员的 AtCoder 账号和战绩。

根因是 AtCoder / 洛谷 / 牛客的账号绑定和平台战绩之前存的是**全局一份**，谁后同步归谁。
这一版改成：

- **平台绑定按 CF 账号各存各的**：每个 CF 号绑定自己的 AtCoder / 洛谷 / 牛客账号，切换时绑定跟着走
- **平台战绩也按账号归属**：切换账号后看到的都是自己的数据
- 老用户升级无感：已有的绑定和战绩会自动归到主账号名下

升级后第一次，建议到「设置」里把自己的 AtCoder / 洛谷账号重新确认一遍（大部分情况会自动带过来），点一次同步即可。

### 新平台支持：Linux

桌面程序从这一版起同时发布 Windows 和 Linux 安装包。功能与 Windows 版完全一致（训练计划、
五大平台战绩、AI 题解都有）。网页版（`node server.js`）本来就跨平台，不受影响。

### 其他

- 上一版（v1.0.14）的 AI 题解：如果还没配 Key，去「设置 → AI 题解」填一个
  （DeepSeek / 通义 / Kimi / 智谱 / 本地 Ollama 都行），详见 v1.0.14 的发布说明。
