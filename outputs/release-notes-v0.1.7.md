## ACM 训练台 v0.1.7

这一版的主线是「题从哪来」：训练计划不再只能出 Codeforces 的题，洛谷和 AtCoder 都能按比例混进来；
比赛日历也从一个平台变成了三个，洛谷和 AtCoder 的赛程都能看到。

### 下载

下载下方的 `ACM Trainer Setup 0.1.7.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 比赛日历：洛谷和 AtCoder 的赛程也进来了

日历顶部多了来源筛选（全部 / Codeforces / 洛谷 / AtCoder），每个按钮上带着各自的场次数，
点一下只看那一家。数据来源和口径：

- **Codeforces**：还是原来的官方接口，只列未来一周内还没打完的。
- **AtCoder**：抓 `atcoder.jp/contests/` 的 upcoming 表格（日本时间已换算成本机时区），同样只留一周内。
- **洛谷**：拿 `contest/list` 里的比赛名单，**只保留 rated 的场次**（洛谷自己的月赛、LGR、SCP 模拟，
  以及 ICPC 区域赛重现赛这些计分场），不计分的娱乐赛不占位置。洛谷公布得早，这边按你选的窗口列。

三家都是抓不到就静默跳过，只用能拿到的那部分，不会因为一家挂了就整页空白；抓回来的数据缓存 12 小时。
顺便修掉了洛谷这边的抓取：它的比赛列表接口要带 cookie，不带会被服务器一直 302，直接报网络错误。

### 训练计划：可以混进 AtCoder 和洛谷的题

设置 → 题目来源里有两个开关，勾上就会按比例进题单，**不勾就还是纯 Codeforces**，和以前完全一样。

**AtCoder**：填个 AtCoder 用户名，点「同步 AtCoder 数据」。题库和难度估计都来自 Kenkoooo 的
AtCoder Problems 公开接口，不需要登录 AtCoder，也不会往对面提交任何东西。Kenkoooo 的难度是 IRT 估计值，
量级比 CF rating 低一截，统一加 200 折算进练习区间（实测 ABC-C 约 400~530、ABC-D 770~900、
ABC-E 1350~1390、ABC-F 1600~1850、ABC-G 2060~2340，ARC-C 约 2070）。提交记录按游标增量同步，
做过的题自动排除、自动打勾；题库 7 天才换一次。

**洛谷**：先在设置 → 洛谷里选难度档再点「抓取题库」。它是按难度档**等距抽页**抓的——
默认排序下前面几页全是十几年前的题，只抓头几页会让整个题单偏掉；每档抽 8 页（约 400 题），
单线程、1.2 秒一个请求，除入门档之外的 7 档一次抓完约 64 个请求、86 秒。入库按难度档替换，
先抓普及、过几天再抓提高，普及那批不会被清掉，设置里能看到各档分别抓了多少道。
洛谷的标签会翻成 Codeforces 的官方标签（模拟 → implementation、并查集 → dsu…），这样方向配额和
单标签占比上限沿用同一套口径；难度按「档位分数段 + 档内按通过人数摊开」折算，是个估计值，
鼠标停在题单里的「洛谷」角标上能看到真实档位。同步练习页时会把做过的洛谷题标出来。

### 三平台怎么混

两个开关都打开时，题单按 **一半 CF + 四分之一 AtCoder + 四分之一洛谷** 混排，各平台**每天最多一道**：
一天四题就是两道 CF + 一道 AtCoder + 一道洛谷，排期时跨过休息日、某天没空这些边界也会再对一次。
AtCoder 没有官方算法标签，洛谷有 23% 的题自己没打标签，这两批只参与难度分配，不进八个方向的配额，
能力画像也不受影响；有标签的洛谷题和 CF 题一样进方向配额。

实测（245 题的完整计划）：AtCoder 62 题、洛谷 62 题，四个难度档 20/20/20/20 上下，
八个方向配额 4~6 题，自检 16 项全过。

### 计划自检多了三平台相关的检查

设置里的「计划自检」现在会额外核对：AtCoder 和洛谷各多少题、是不是每天最多一道、各占多少比例、
题库上次同步是什么时候。混排跑偏了一眼就能看见。

### 撤掉了自定义背景图

上一版加的「设置 → 背景图片」整块去掉了（包括样式、接口和设置项）。这个功能偏装饰，
和「看一眼今天做什么」的定位不搭，留着反而让设置页变长。

### 顺手的细节

- **今日卡片**那个「今天补一个方向」的入口可以在设置里关掉了（设置 → 今日卡片）。
- 题单里 AtCoder 题带 `AtCoder` 角标、洛谷题带 `洛谷` 角标，鼠标停上去能看到各自的原始难度。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
