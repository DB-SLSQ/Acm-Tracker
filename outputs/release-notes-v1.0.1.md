## ACM 训练台 v1.0.1

版本号跳到 1.0.x，算一个新的起点。这一版加了两页新东西（题库、帮助）、换了图标，
并且把 AtCoder 那边的数据接得更全。

### 下载

下载下方的 `ACM Trainer Setup 1.0.1.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 新页面：题库

左边菜单多了「题库」，从一个地方翻完三个平台的题：

- 关键词（题号或题名）、难度区间、算法标签、来源（Codeforces / AtCoder / 洛谷）、
  「只看没做过的」都能筛，排序有难度升降序、通过人数、最新比赛四种，一页 50 道。
- **随机来一道**：按当前筛选条件随机挑一道，并且告诉你是在多少道里挑的。
  卡住不想挑题的时候，点一下就有事做。
- 做过的题在列表里会压暗并标上「已通过」，试过没过的会写「试过 N 次」。

题全在本地题库里（CF 的题 + AtCoder 的题 + 抓过的洛谷题），这个页面不联网也能用。
筛选是在服务端做的——一万六千道题没必要全塞给浏览器。

### 新页面：帮助

左边菜单多了「帮助」，把我自己踩过、也被问过的十几件事写成 QA，点标题展开：

- 数据存在哪、会不会上传；换电脑怎么搬
- Codeforces 一直转圈 / 洛谷报 `fetch failed` / AtCoder 的数据从哪来
- 点了按钮弹「接口不存在」是怎么回事（0.1.7 的老毛病）
- 补题队列里为什么全是做过的题（0.1.9 修的那个）
- 计划会不会自己变、「落后几天」怎么算、每天那四档是什么
- 推题模型为什么一直没启用
- 怎么检查更新、有问题去哪问

以后遇到问题先翻这一页，比在群里等回复快。

### 图标换了

换成新立绘里的头部徽章（赛博霓虹那版）：外圈青→紫→品红的渐变描边，里面是头部特写。
做成 16 / 24 / 32 / 48 / 64 / 128 / 256 七个尺寸打进 exe，任务栏和开始菜单里都能看清。
选头部而不是全身，是因为图标在任务栏里只有 16~32 px，全身构图缩下去就只剩一团霓虹。

### AtCoder 的数据接得更全

- **赛程只列计分场次**，并把计分区间写在标题下面（例如 `~1999`、`1200~2799`、`全员计分`），
  PAST、AWC、AAL 这类不评分的练习赛不再占位置——和日历里「洛谷只列 rated」是同一个口径。
- **平台数据的 AtCoder 卡片多了两项**：通过题数的全站排名、计分总分，来自 Kenkoooo 的用户接口。

顺便记一笔：一开始想直接用 Kenkoooo 的 `contests.json` 当赛程，实测（2026-09-28）那份文件
最新一条停在 9 月 27 日、**未来一场都没有**，会直接把日历搞空，所以赛程仍然抓官方比赛页的表格。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
