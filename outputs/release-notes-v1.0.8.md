# ACM 训练台 v1.0.8

这一版加了两样东西：**比赛日历接上牛客**，以及一个新页面「**待补题**」。

### 下载

下载下方的 `ACM Trainer Setup 1.0.8.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

---

### 1. 比赛日历：多了牛客

左侧菜单 →「比赛日历」，筛选条多了一个「**牛客 N**」按钮，和 Codeforces、洛谷、AtCoder 摆在一起。

- 牛客的比赛（国庆集训派对、牛客周赛、小白月赛、暑期多校这些）现在会一起列出来，
  每行左边标着「牛客」，点进去就是牛客的比赛页。
- 只留牛客自己的场次。牛客那个日历接口其实把 Codeforces、AtCoder 也一起返回了，
  照单全收会在列表里变成两行重复的，所以按来源过滤掉了。
- 赛程是真实抓的，不是手写的表。抓不到的时候（断网、对方改页面）会自动退回上一份缓存，
  日历照常能看别的平台，不会整个空掉。

### 2. 新页面：待补题

左侧菜单 →「**待补题**」。一句话：**一个「这题没做完，回头补」的待办清单**。

它和原来那个「补题队列」不是一回事，别搞混：

| | 补题队列 | 待补题（新的） |
|---|---|---|
| 题目从哪来 | 自动扫你的 Codeforces 提交记录，挑「提交过但没过」的 | 你自己加，或者从训练日程里自动收 |
| 能不能加牛客的题 | 不能（牛客没有提交记录可扫） | **能** |
| 能不能自己改 | 不能 | 能改题名、链接、备注 |

具体能干什么：

- **自动收**：训练日程里「日子已经过了、但还没打勾」的题，打开这一页时会自动收进来。
  每道后面会写着「日程收进 · 原定 10月1日 周四」，你就知道它是哪天的债。
- **自己加**：点「添加题目」，一行写一道，**贴题目链接或者只写题名都行**：
  ```
  https://codeforces.com/problemset/problem/1555/D
  https://ac.nowcoder.com/acm/contest/140729/D
  牛客小白月赛138 D 期望
  2173A
  ```
  第一行是 Codeforces 链接 → 自动认出平台、补上难度、题名都填好；
  第二行是牛客链接 → 本站没有牛客题库，那就老老实实只存链接，不瞎编难度；
  第三行只有题名 → 原样存下来；第四行是个裸题号 → 也能对上题库。
  **你加什么就是什么，不会因为「题库里查不到」被丢掉。**
- **改和删**：每行右边「编辑」（改题名 / 链接 / 备注）、「删除」。
- **勾进度**：左边的勾选框，勾上就算补完了；列表上方有「待补 / 已补 / 全部」三个切换。
- **清空已补**：补完的一键清掉，只留还没补的。
- 如果能对上题库的题，你在 Codeforces / 洛谷 已经通过了，行上会亮一个绿色的「已通过」，
  提醒你该勾掉了（不会替你自动勾，你自己说了算）。

**删掉的自动题不会自己回来。** 从日程里收进来的题，你删了之后，下次打开也不会再被收一遍——
记着你这个决定了。手动加的题删了之后再贴一次链接，还是能重新加回来的。

### 数据还是在你自己的电脑上

所有东西（计划、进度、待补题、比赛数据）都存在本机
`%APPDATA%\acm-trainer\data\trainer.db`，不上传任何服务器。牛客的赛程是公开信息，
跟抓 Codeforces、洛谷赛程一个道理。
