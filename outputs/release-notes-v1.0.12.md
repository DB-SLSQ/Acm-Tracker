## ACM 训练台 v1.0.12

这一版把首页整个换了张脸：**「今日驾驶舱」**。左边一条图标导轨，中间是今天的题单，
右边是进度环、补题、赛程，顶上多了一条吸顶栏，还多了一张各 OJ 的过题分布饼图。

顺手修了两个真问题：**AtCoder 的过题数少算了十几倍**，以及**主区左右各空掉 300 多像素**。

### 下载

下载下方的 `ACM Trainer Setup 1.0.12.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 新版首页长什么样

- **左侧图标导轨**：原来的文字菜单换成一列线性图标，鼠标移上去才展开文字；**边缘可以拖着调宽度**，
  拖到 96~320px 之间，双击回到默认宽度。宽度存在服务端，关掉重开还在。
- **顶部吸顶栏**：滚到哪儿都能看见当前账号、分数、距离目标还差多少。
- **目标爬升轨道**：从当前分数到目标分数拉成一条轨道，中间几站就是各阶段的达标线。
- **三段式今日题单**：按你现在的分数自动分成热身 / 主攻 / 冲刺，每段的难度区间写在标题上。
- **右侧数据栏**：今日进度环、本周完成、待补题（列最近 4 道）、接下来 3 场比赛。
- **过题分布饼图**：五个平台的过题数画成环形图，中间是合计，图例按道数降序排、带占比，
  一眼看出谁是大头、哪个平台还没绑账号。

### 修了什么

**一、AtCoder 的过题数只有真实值的零头。**

以前那个数字是从本地提交记录里数出来的，而本地只存了「能排进训练计划、难度达标」的那部分题，
所以显示 7 道。实际上这个号在 AtCoder 上过了 131 道。现在改成直接读 AtCoder 官方侧的累计通过数，
另把「其中有多少道进了本地题库」单独标一格，两个口径不再混着显示。

**二、主区左右各空掉一大条。**

换侧栏布局的时候，老版「居中 1080px 窄栏」的三条规则忘了删，一直在生效。1920 宽的屏幕上，
主区实际只有 1080px、左偏移 467px，左右各空 334px；2560 宽下更夸张，各空 654px。
删掉这几条宽度上限后，主区撑满侧栏以外的全部宽度，只剩 32px 内边距。

### 题目来源可以只留一个平台

设置页的「题目来源」现在 **Codeforces / AtCoder / 洛谷三个都能勾**：

- 三个都不勾 → 默认全按 Codeforces 推（和以前一样）
- 只勾洛谷 → 只推洛谷的题
- 底下会实时告诉你怎么分：勾的平台按设定比例分题量，Codeforces 拿剩下的

改动只在你动手调整时才生效，**不会平白把你手上的计划重排一遍**。

### 验证

- 界面改动全部在真窗口里截了图：1920 / 2560 / 1280 三种宽度，外加窄屏和空库空态。
- 侧栏拖拽实测：拖到 388px 被正确夹到上限 320，双击回到 132。
- 题目来源的 7 种勾选组合全部走了一遍，份额计算符合预期。
- 饼图在宽屏（图例一行五个）、窄屏（饼图在上、图例竖排）、一个平台都没绑（空态提示）三种情况都验过。
