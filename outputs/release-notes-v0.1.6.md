## ACM 训练台 v0.1.6

这一版主要是「界面重做 + 每天这套题更懂你」：整个程序从一整页往下滑，改成了左边菜单分页；
今日卡片长出了手感反馈、赛前热身、复盘卡；数据也有了备份和迁移。

### 下载

下载下方的 `ACM Trainer Setup 0.1.6.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 界面：改成左边菜单 + 分页

以前是十几个面板从上往下排一长条，找东西全靠滚。现在左边是固定菜单，分成「训练 / 数据 / 其他」三段，
点哪一项右边换哪一页，同时只显示一页；地址栏会跟着变（`#/plan` 这种可以直接存成书签）。
「账号」和「当前水平」合并成了一页，进来填用户名、下面直接看水平，不用再先跳一页。
面板的「展开/收起」也一并去掉了——菜单本身就是导航。

### 可以放自己的背景图

设置 → 背景图片：挑一张本机图片（PNG / JPG / WebP，最大 12 MB）当整个训练台的背景。
**图片存在你自己的数据目录里，不会上传到任何地方**；显示强度和模糊随时能调，觉得太花就点「恢复默认背景」。

### 今日卡片：今天这套题更懂你了

- **做题手感**：每道题后面四个按钮——秒了 / 刚好 / 卡住 / 看题解。提交记录只能看出「过没过」，
  看不出「是不是秒的」「是不是看题解才会的」，这两个才是最该拿来调练习区间的信号。标了之后会折算成
  练习区间上下挪（最多 ±50 分），写在计划说明里。
- **赛前热身包**：24 小时内有 rated 比赛时，卡片上方自动给 1~2 道比当前水平低一点的热身题。
  比赛当天做新知识点没意义，先热手。
- **复盘卡**：最近 20 题和再往前 20 题对比——平均难度、一次通过的比例、主要练了哪些方向。
- **补一个方向**：某天想单独补一下（比如字符串），选个方向一键加 3 道进今天，不占计划配额。
- **复制题单**：一键把今天的题复制成 Markdown，贴群里或记笔记都行。

### 成长页：改成网格，每张图都写了「怎么看」

以前是长条堆叠，看着像黑箱。现在是大卡片（每周题量，柱子=题数、颜色=当周平均难度、圆点=比赛涨跌）
加两张小卡片（每场比赛前两周练了多少、各方向 75 分位的周变化），每张下面都有一段小字说明这张图怎么看。
另外多了一句**结论**：赛前做满 8 题的场次和练得少的场次分开算平均涨跌，直接告诉你训练量和成绩目前是什么关系
（样本不够就老实说「看不出关系」）。曲线还能导出成 SVG 图片。

### 计划页可以「按天看」

计划页筛选栏右边多了「按天看」：整份计划按日程分成一天一个小块，可以折起来，
每块标题写着「2 题 · 1700 / 2000 分 · 跨度 300 · 已完成 2/2」，今天那块默认展开。

### 数据安全

设置 → 数据安全：

- **备份数据库**：一键存到数据目录的 `backups` 里（用 SQLite 自带的备份方式，不会备份到写了一半的库）
- **导出 / 导入训练数据**：设置、勾选进度、屏蔽表、虚拟赛记录、做题手感打包成 JSON，换电脑能搬
- **检查更新**：直接问 GitHub 最新版本是多少，有新版本会给你下载地址

### 计划自检升到 8 项（数据体检）

设置里的「计划自检」（也能直接开 `/selftest.html`）除了原来的每日题序、每日难度跨度、四档均分、
方向配额、题量，又加了三项体检：题库多少道 / 上次同步什么时候、推题模型的状态、数据库体积。
一键看本机数据有没有该修的。

### 顺手的细节

- **做题记录**和**账号对比**里隐藏了「题库里查不到的题」（gym、很早的比赛，没难度没标签），
  只在上面标一句有多少道，免得看着像数据丢了。
- **键盘操作**：计划表里 `↑`/`↓` 移动高亮行、空格打勾，几百行的题单不用一直摸鼠标。
- **紧凑模式**：题单太长时可以切紧凑（设置 → 列表密度）。
- **计划生成更快**：题库读一次缓存起来，不再每次请求都从数据库拉一万多条。
- 修掉一个界面 bug：上一版有几个设置块被渲染到了页脚下面（样式全丢），现在都在设置页里。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
