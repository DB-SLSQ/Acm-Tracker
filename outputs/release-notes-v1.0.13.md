## ACM 训练台 v1.0.13

这一版回到「计划稳不稳」这件事上。

有人反馈：**昨天做完当天的题，第二天再打开，发现昨天那几天又冒出几道没做过的新题，
还被算进了待补题**。顺着这条线索查下去，发现是两层原因叠在一起——一层在「计划的沿用」，
一层在「日程的排期」，两处都修掉了。

### 下载

下载下方的 `ACM Trainer Setup 1.0.13.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 修了什么

**一、「沿用旧计划」以前是句客气话，实际每次都在悄悄重挑题。**

按设计，只要设置没变，程序应当沿用你手上那份计划：做过的题留在原位，不会被换成别的题。
但它其实每次都会把整套挑题算法重跑一遍，只是把上次的题号当作「优先保留」的提示传进去。
而重算有两个输入根本没被纳入「计划有没有变」的判断：

- **做题手感反馈**（标了「秒了」或「看了题解」，练习区间就整体上下挪）
- **新做过的题**（各方向的名额会按强弱重新分配）

这两个一变，区间挪位、名额重排，落在区间外的旧题就被丢掉、补一批新题进来，题号和顺序全变。

实测：一份 60 题的计划，注入几条「秒了」反馈，**换掉了 14 道题**；再把计划里前几道标成已通过，
**又换了 3 道**。换进来的题你没做过，日程便判定「过期没做完」，自动收进待补题——这正是反馈里的现象。

现在改成：**沿用旧计划时，题号一律以存档为准**，重算结果不再作数；只有「题库里已经找不到的」
和「你亲手屏蔽的」才会从计划里拿掉。区间、四档、方向名额这些展示信息照常实时更新。

**二、日程只钉住了「做哪几题」，没钉住「哪一天做」。**

上面那条修好的是「计划被重挑」，还有一层更隐蔽的：哪天做哪几题，一直是**每次打开页面现算的**，
日期和题目之间没有任何绑定。于是任何一个设置变了——每周题量改一改、多勾一天休息、
计划重新生成后起始日挪到今天——**过去那几天都会跟着整体重排**：昨天做完的题第二天换了别的，
前几天甚至可能直接消失。

实测：把每周题量从 50 改成 20，过去三天共 **22 道题**全部移位。

现在新增了一张「日期 → 题号 + 顺序」的存档表，每次排完日程就把**今天以前**的日子记下来。
之后无论怎么改设置，已经过去的日子都原样摆回原位，界面里会标上「已锁定」。
两个刻意的取舍：① 过去的日子就算现在被勾成休息日，也不把记录摘掉（历史不能被掏空）；
② 点「重新生成计划」只清今天及以后的安排（未来的题本来就该跟着设置走）。

### 影响范围

已经产生的错误待补题**不会自动消失**——它们是按老逻辑收进来的，留在队列里。
可以手动删掉（删掉的不会被再收回来）。

### 验证

- 计划沿用：注入手感反馈 / 标记已通过 / 屏蔽题目 / 重新生成，逐项验证题号与顺序一动不动。
- 日程排期：改题量、加休息日、把过去某天标成没空、不重不漏、待补题集合不变、
  存取边界与「只清今天及以后」共 22 项全部通过。
- 真机端到端：把过去三天钉进存档后，改题量并重新生成计划，那三天在界面和数据库里都一字未动。
