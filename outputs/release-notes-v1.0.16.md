## ACM 训练台 v1.0.16

这一版四件事，三件围绕**团队训练**，一件是新增 **VP 查询**。

### 下载

**Windows**：下载下方的 `ACM Trainer Setup 1.0.16.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

**Linux（Ubuntu / Debian 等）**：

- `.AppImage`：下载后 `chmod +x ACM.Trainer-1.0.16.AppImage`，直接双击/命令行运行；
- `.deb`：`sudo dpkg -i ACM.Trainer-1.0.16.deb` 安装，装完在应用菜单里找 ACM Trainer。

### 团队训练：分工可以手动改了

之前「对内分工」是机器按战绩和方向算的，算出来什么样就是什么样，没法调。这一版起分工矩阵**直接可编辑**：

- 每个题单方向的主攻可以下拉换人，副攻点头像 chip 开关
- 改完点「保存分工」，保存的手排方案机器不再自动覆盖
- 想恢复机器分配，点「重新分配」即可清掉手动标记重新算

### 团队训练：不打 CF 的队友也能手动设实力

有队友不刷 CF，机器没法估他的强度，排出来的题就会不合适。现在每个队员卡上多了一个「设实力」按钮：

- 手动填一个 CF 等效实力（比如 1600），排题就按这个强度来
- 填过的队员卡上会显示「手动实力」标记，和 CF 实分区分开
- 想取消手动值，把框清空保存即可，自动回退 CF 实分

### 新增：VP 查询

区域赛 VP 链接散在 QOJ 和 CF 上不好找，侧栏新增「VP 查询」一栏：

- 自动抓取 QOJ 和 Codeforces 上的 ICPC 区域赛类比赛（当前 700+ 场）
- 支持按名字搜索，一键跳转原题链接
- 结果缓存 24 小时，不用每次都等抓取

### 新增：QOJ 平台

平台列表加上 QOJ：

- 「设置」里可以绑定 QOJ 账号，平台卡片显示 QOJ 徽章、点击直达个人主页
- 注意：QOJ 的提交记录需要登录才能看，所以 QOJ 暂时**只做绑定和入口**，不抓战绩

### 其他

- AI 题解（v1.0.14 上线）：如果还没配 Key，去「设置 → AI 题解」填一个
  （DeepSeek / 通义 / Kimi / 智谱 / 本地 Ollama 都行），详见 v1.0.14 的发布说明。
