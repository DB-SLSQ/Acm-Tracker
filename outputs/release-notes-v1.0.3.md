## ACM 训练台 v1.0.3

两个开发中的需求：**「当前水平」页也能换题了**，以及新的一页 **「拼好题」**。

### 下载

下载下方的 `ACM Trainer Setup 1.0.3.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 当前水平页：今日卡片上也能换题

以前「换一道 / 放最后」只在训练计划页里有，得切过去才能点。现在今日卡片每道题后面也带上这两个按钮，
行为和计划页完全一致（同一个接口、同一份记录）：换掉的题会记在后台，重新生成计划也换得回来，
「放最后」会真的重排顺序、日程跟着变。

顺手修了个显示问题：换成 AtCoder 的题时，右下角提示写的是内部编号（`3000024C` 这种），
现在写界面上那个题号（`ABC025C`）。

### 新页面：拼好题

左边菜单新增「拼好题」（在「历年比赛」下面）。选一场 Codeforces + 一场 AtCoder，凑成一套：

- 单打一场 CF Div.2 才 6 题、一场 ABC 七八题，都不够一场区域赛的量；两场拼起来十几题，
  两边的难度分布也不同，练起来有起伏。实测拼出来是 10~13 题、难度跨 800~2700。
- **只挑你没打过的场**（按有没有提交记录判断，不是按通过没通过——打过但零通过也算打过），
  并且**只从最近一年半以内挑**，太久远的题难度标定和现在不一样，练了意义不大。
- 在最近的 60 场候选里随机取，所以同一个类别的题不会老是同一场；点「换一套」就重拼。
- 指定类别最近正好没有没打过的场次时，会自动换成别的类别，并在上面写一句说明。
- 拼完可以「复制这一套」，导成 Markdown 贴群里或记笔记。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
