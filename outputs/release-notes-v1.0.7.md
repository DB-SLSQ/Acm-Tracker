## ACM 训练台 v1.0.7

修一个桌面版才有的毛病：**点「新建队伍」没反应**。

### 下载

下载下方的 `ACM Trainer Setup 1.0.7.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 修了什么

上一版（1.0.6）的「新建队伍」「改名」这两个按钮，在桌面版里点了没有任何反应——不弹窗、
不报错、也不建队。现在好了。

原因是桌面版用的是 Electron，而 **Electron 把浏览器里的 `window.prompt()` 这个函数
直接移除了**，一调用就抛异常。这个异常不会弹窗提示，只写进控制台，所以从界面上看就是
「点了没动静」。更坑的是网页版完全正常，光在浏览器里试根本发现不了。

修法是把这类「弹个输入框问一句」的地方全部换成自己画的浮层，不再依赖浏览器内置的 prompt。
一共四处，顺手一起改了：

- 新建队伍（起队名）
- 改名（改队名）
- 补抓平台数据（问 AtCoder 用户名、问洛谷 UID，现在是连续两个小框，比原来更清楚）

新弹框的行为和以前一样：回车确定、Esc 或点遮罩取消；队名这类不能为空的地方，
留空点确定会停在框里不让你提交。**「删除队伍」用的是浏览器确认框，Electron 支持它，
所以一直没坏，这次也没动。**

### 如果你之前遇到这个问题

上一版里这四处都是坏的，包括：新建队伍、改队名、补抓平台数据会连着弹两次框（实际上
一次都弹不出来）。升级到这一版就都好了。已经建好的队伍不受影响。

### 说明

这次是纯修复，没有新功能。团队训练的其他部分（三平台抓数据、队内分工、不撞题排题）
和上一版一样。
