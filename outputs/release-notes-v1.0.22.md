这一版加的是**更新检查**：装了这个版本以后，有新版本不用再去群里问「出到几了」。

## 一、打开就告诉你有没有新版本

以前只有「设置 → 数据安全 → 检查更新」这一个入口，而且查完只是把一串链接打在提示行里——得自己复制到浏览器。现在：

- **启动时自动问一次 GitHub**，6 秒后跑，不跟计划生成抢带宽；结果在服务端缓存 6 小时（GitHub 未登录限额每小时 60 次，缓存之后基本不占额度）。
- 有新版本：右下角弹一条提示，**「去下载」一键打开安装包下载页**；页脚版本号后面同时点亮一个「有新版本 vX」的小标签。
- 点那个小标签直接跳到设置页的更新卡片，卡片里有：下载按钮、Release 页面、**「这版改了什么」**（就地展开更新说明，不用去网页看）、「这个版本先不提醒」。
- 关掉应用再开不会重复烦你：点过「先不提醒」的版本，之后只在页脚留着标签，不再弹提示。
- 应用长期开着的话，切回窗口时如果距上次检查超过 6 小时会补问一次。

## 二、手动「检查更新」也变好用了

设置 → 数据安全 → 「检查更新」现在是**强制刷新**（跳过缓存），查完直接在下面展开同一张卡片，不再是「当前 1.0.21：链接」。

断网 / GitHub 不通时不会报错糊你一脸：有上次的结果就拿出来用（卡片上会注明「这是上次的结果，刚才没连上 GitHub」），一次都没查成功才提示失败。

## 三、为什么不做「自动下载安装」

安装包是 NSIS，自动安装要么接 electron-updater（需要签名和 latest.yml 配套），要么静默运行安装器（会碰「覆盖正在运行的程序」和各种权限弹窗）。相比之下「提示 + 打开下载页，你自己双击装」最稳，也不会在别人机器上悄悄装东西。

---

说清楚一点：**这个版本本身还是手动装的**——1.0.21 及更早的版本没有更新检查，得手动升到 1.0.22，从下一个版本开始才能自动提醒。

验证：

- 接口：第一次问 GitHub 1.7 秒，第二次命中缓存 0.2 秒；`?force=1` 强制刷新；按平台挑附件（Windows 拿 `.exe`，Linux 优先 AppImage）。
- 界面（Electron 真跑）：假装远端有 9.9.9，启动 6 秒后右下角弹「发现新版本 v9.9.9（现在是 v1.0.21）」并带「去下载」；页脚出现「有新版本 v9.9.9」；点标签跳到设置页并滚到卡片；「这版改了什么」展开后 Markdown 被理成纯文本（`##` 去掉、`-` 变 `·`、`**加粗**` 去掉星号）。
- 回归：钉子 22 项、接口 23 项、计划钉住 7 项、今日卡片 9 项、团队功能 29 项，全通过。
