## ACM 训练台 v1.0.2

把上个月那两页「像 cftracker / AtCoder Problems 那样翻题」的东西做全了：
题库页改成难度可拖的筛法，另外多了「历年比赛」一页。

### 下载

下载下方的 `ACM Trainer Setup 1.0.2.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 新页面：历年比赛

左边菜单新增「历年比赛」（在「题库」下面），一场比赛一行：

- 一行里是 **日期 · 比赛名 · 分类 · 我做过几题**，下面是这场每道题的色块，
  底色就是难度色，做过的压暗；鼠标停上去看题名，点一下去原站做题。
- 分类可以筛：Div. 1 / Div. 2 / Div. 3 / Div. 4 / Div. 1+2 / Educational / Global Round /
  ABC / ARC / AGC / 其他，每类都带场次数。
- 状态可以筛：我打过的、还有题没做出来的。
- **随机一场**：在这些比赛里随机挑一场还有题没做的——不知道刷什么的时候按一下就行。

数据是本地题库按比赛分组的，所以有题目的比赛才会列（实测 2792 场）。洛谷不在这里，
它的题没有「比赛」这个层级。

### 题库页：难度改成可拖，加了推荐

- **难度区间改成双滑块**，拖着看题量实时变。拖到底就是全部题目（不会把没难度的题漏掉）。
- 新增**通过状态**筛选：全部 / 只看没做过的 / 只看做过的。
- 新增**按我的水平推荐**：拿你现在的 rating 往上抬一档（-100 ~ +300 分）随机挑一道还没做过的，
  并告诉你这个区间里一共有多少道候选。卡住不知道刷什么的时候按它。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。
