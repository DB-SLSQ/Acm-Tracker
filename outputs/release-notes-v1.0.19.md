## ACM 训练台 v1.0.19

这一版只改一件事：**加队员不用再填 Codeforces 用户名了**，写个名字就能加。

### 下载

**Windows**：下载下方的 `ACM Trainer Setup 1.0.19.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

**Linux（Ubuntu / Debian 等）**：

- `.AppImage`：下载后 `chmod +x ACM.Trainer-1.0.19.AppImage`，直接双击/命令行运行；
- `.deb`：`sudo dpkg -i ACM.Trainer_1.0.19_amd64.deb` 安装，装完在应用菜单里找 ACM Trainer。

### 改进：加队员只需要一个名字

以前加人第一个框是「Codeforces 用户名」并且标着**必填**，队友不打 CF 就卡在那里加不进去。

现在这个框改成「**队友名字**」，随便写：

- **名字正好是他的 CF 用户名**（比如 `tourist`）→ 自动抓分数、做题记录，跟以前一样；
- **名字是中文、或者随便起的**（比如「阿杰」「小李」）→ 一样能加，只是不抓 CF 数据；
- 没绑 CF 的人，在队员卡片上点「**设实力**」标一个「相当于 CF 多少分」，排题和知识画像都按它算，
  跟之前给不打 CF 的队友标实力是同一套逻辑。

几个配套的小改动：

- 加人成功后的提示会直说「没关联 Codeforces，想让 TA 参与排题就点设实力标一个分数」；
  已经标过实力的不再提醒；
- 只有「真的去抓了」的平台才会出现在结果里——没填 AtCoder / 洛谷账号时不再显示「AtCoder 0 题」，
  那种显示看着像抓失败了；
- 名字里带中文的不会再去 CF 问一遍（一定查不到），省一次请求；
- 页面顶部的输入框现在真的有用了：在里面打了字再点「加入…」，会直接预填进弹框；
- 队员名字很长时，卡片右上角的「设实力 / 移出」不会再被挤成两行。

加人仍然是先记进队伍、再去抓数据：抓取慢或者某个平台挂了，人已经在队里，之后在卡片上点
「补抓平台数据」补上即可。
