## ACM 训练台 v1.0.6

这一版加了一个新页面「团队训练」：一支队伍几个人一起练，最怕的是三个人的题单高度重叠——
弱项都差不多，一起去补同一块，结果卡在同样的地方。这个页面把八个知识方向先分给队员，
每个人练自己的那一块，排题的时候队内也不会撞题。

### 下载

下载下方的 `ACM Trainer Setup 1.0.6.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 团队训练

新页面在左边菜单「训练计划」下面。用法分三步。

**第一步：建队伍、加队员。** 点「加入…」会弹出一个小框，让你分别填这个人的
Codeforces、AtCoder、洛谷账号。三个平台分开填，填了的会一起抓回来：

- **Codeforces** 是必填的，它是这个人的主账号，rating 和各种统计都挂在这上面；
- **AtCoder** 填用户名（就是个人主页地址里那个，区分大小写）；
- **洛谷**填 UID，是主页地址里的那串数字。

只填 CF 也能加，但**不建议**——队内分工是按八个方向的做题情况算的，少了两个平台的数据，
这个人的画像就是残缺的，分方向时会把他算得比实际弱，容易让好手去干边角活。
所以界面上会明确标出谁缺哪个平台：队员卡片的标签会变灰，总览表有一列「数据来源」，
下面还有一行提示写清楚谁缺什么。缺的随时能在卡片上点「补抓平台数据」补上。

**第二步：分方向。** 点「重新分配方向」，系统按每个人「相对自己水平」的强弱来分：

- **主攻**的方向三个人不重叠，一个人一块地深挖；
- 每人再带两个**副方向**，是拿来补自己最短板的，允许和别人主攻重叠——
  三个人的时候八个方向刚好被主攻占满，副方向再去抢地盘就没意义了。

分完会**钉住**，之后排题一直按这份分工走，不会今天你主攻图论、明天换他主攻，练到一半方向漂了。
以后数据更新了想重算，再点一次就行。

**第三步：排题。** 填每人几道、目标分多少，点「排题」。每个人排到的题跟着他自己的水平走
（分低的不会全是超纲题），难度四档轮着来，而且**全队不重复**。
标「主攻」的是他负责的那块，标「副」的是补短板用的。

### 关于「要不要上云端」

现在是**纯本地**的，队伍、分工、进度全存在本机，不联网也不上传。
几个人的数据分别按各自的账号存，互不干扰。如果以后想三个人共用一份队伍数据
（比如共享进度、在一台机器之外也能看），那需要再加一层云端同步，现在还没做。

### 数据放在哪

全部保存在本机 `%APPDATA%\acm-trainer\data\`，不上传任何服务器，不需要登录 Codeforces，
也不会索取你的账号密码。也可以直接跑网页版（`npm.cmd start`，浏览器打开 `http://127.0.0.1:5173`）。

### 一点说明

用别人的账号抓数据，抓的都是**公开信息**（Codeforces 的公开 API、AtCoder 的公开成绩页、
洛谷的公开练习页），不需要对方给密码，也不需要对方做什么。只有一种情况会抓不到：
对方在洛谷把练习数据设成了私密，这种情况程序会明确告诉你原因，不会静默算成 0 题。
