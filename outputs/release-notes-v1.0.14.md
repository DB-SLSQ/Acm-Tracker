## ACM 训练台 v1.0.14

这一版带来了一个新功能：**AI 题解**。每日题单里的每一道题，都可以让 AI 写出「思路 + 代码」，
点开就能看，不用再自己去翻题解区。

### 下载

下载下方的 `ACM Trainer Setup 1.0.14.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 新功能：AI 题解

- **今日卡片**的每一行题多了一个「AI 题解」按钮，点一下，AI 就会把这道题的思路和参考代码写出来；
  卡片右上角的「AI 题解」可以**一键批量生成今天还没生成的**。
- 生成过的题会变成「AI 题解 ✓」，点开看弹窗：思路、参考代码、一键复制、随时重新生成。
- 生成的题解会**存在本地数据库里**，下次打开还在，不用重新生成。

#### 需要先配置一个 API Key

打开「设置 → AI 题解」，填四样东西：

| 配置 | 填什么 | 说明 |
| --- | --- | --- |
| 接口地址 | `https://api.deepseek.com/v1`（默认） | 任何 OpenAI 兼容接口都行 |
| 模型 | `deepseek-chat`（默认） | 按你的接口填 |
| API Key | 你自己的 Key | 只存在本地，不上传，界面里只显示末四位 |
| 语言 | C++17 / Python 3 | 参考代码用什么语言写 |

用的是 OpenAI 兼容协议，所以 **DeepSeek、通义、Kimi、智谱、本地 Ollama、各种中转站都能接**，不绑死任何一家。Key 只存在你自己电脑的本地数据库里，程序界面拿到的也只是「已设置 + 末四位」，不会显示明文。

#### 关于题面

生成前会先尝试抓题面，抓到了 AI 就按完整题面写，抓不到就按题号推，并在弹窗里如实标注。

- AtCoder / 洛谷：能抓到题面 ✅
- Codeforces：官方有 Cloudflare 防护，程序抓不到，会降级为「只给题号」——多数情况下模型认识常见题，但**建议以题号为准自己核对**。

### 顺手修了三个问题

1. **已生成的题解认不出来。** 程序启动时拉取题解列表的时机不对，导致「已经生成过的题」
   一直显示成没生成——点一次就重新生成一次，白烧 token。已修。
2. **按钮文案撞名。** 新按钮的已生成状态原来叫「看题解」，和做题手感反馈里的「看题解」
   （意思是"这题看了题解才会的"）撞了，两个并排出现分不清，已改成「AI 题解 ✓」。
3. **今日卡片被挤坏。** 加了新按钮后，窄窗口下题目标题会被挤成一个字一行。已改成允许折行，
   标题保住最小宽度。

### 验证

- 真机实测（DeepSeek 官方接口）：洛谷 P11777 用时 8.3 秒、P1054 用时 11.2 秒，
  题面抓取均成功，思路与代码完整落库。
- 安全检查：设置接口的返回里搜不到完整 Key（只回「已设置」+ 末四位）。
- 端到端回归：配置保存、Key 不外泄、提示词含题面、落库、无 Key 时给出人话提示，全部通过。
- 布局：今日卡片在窄窗口下标题不再竖排，按钮组自动折行。
