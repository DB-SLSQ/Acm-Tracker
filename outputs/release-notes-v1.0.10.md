## ACM 训练台 v1.0.10

比赛日历再多一家：**力扣**。

### 下载

下载下方的 `ACM Trainer Setup 1.0.10.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

### 这版加了什么

比赛日历现在同时看五家：Codeforces、AtCoder、洛谷、牛客、力扣。顶上那排筛选按钮多了一个「力扣 N」。

力扣的比赛就两类，节奏很固定：

- **周赛**：每周日上午 10:30，1.5 小时
- **双周赛**：隔周周六晚 22:30，1.5 小时

所以一周最多两场，14 天的窗口里一般能看到 2~3 场。这版装好的当天实测：第 522 场周赛（10/4）、
第 193 场双周赛（10/10）、第 523 场周赛（10/11）。

数据来自力扣自己的公开比赛列表接口，**不需要登录、也不用填账号**，跟洛谷、牛客一样是白看的。

### 顺手改的

- 「待补题」里贴力扣的题目链接（`leetcode.cn/problems/...`）现在也能自动认出平台，
  角标显示「力扣」——以前只会显示「自定义」。
- 页脚的数据来源说明补上了牛客和力扣（之前一直漏着）。

### 验证

- `.dev/verify-leetcode.mjs` 17 项全过：接口可达、字段齐全（id / 名字 / 起止时间 / 时长 / 链接）、
  时间窗过滤正确、前端按来源分组的数对得上、待补题能认出力扣链接。
- 另外在真 Electron 窗口里截了图，确认六个筛选按钮排得下不溢出、力扣角标颜色正常、点「力扣」只剩 3 条。

### 说明

和其它外部平台一样，力扣赛程缓存 12 小时，只在打开比赛日历、缓存过期时才请求一次；
抓不到就退回上一次的缓存，页面照常用 Codeforces 的赛程，不会因为力扣挂了整个日历打不开。

一家家加过来，现在外面这四家（洛谷 / AtCoder / 牛客 / 力扣）的接法都不一样：AtCoder 只能抓网页表格、
洛谷要带 cookie、牛客要带 Referer 且按月分页、力扣一个 GET 就全给了。这些差异都记在
`server.js` 的注释里了，以后哪家改接口好照着查。
