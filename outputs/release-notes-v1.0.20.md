这一版只改一件事：**加队友时，AtCoder 和洛谷也跟 Codeforces 一样宽松了**——填错、查不到都只是「跳过」，不再弹「失败」。

以前加队员，CF 名字随便填没关系，但 AtCoder / 洛谷只要填了就会去抓，抓不到就记一条「AtCoder 失败（…）」「洛谷 失败（洛谷用户 ID 是主页地址里的数字）」。队里有人没有这些账号，或者导师只是手快写了个名字，就会被这行红字顶回来，看着像加人失败了。

现在就一个口径：**填了才抓，抓不到就跳过，人照样加进队伍。**

- 名字不像账号的**根本不去问接口**：AtCoder 只认字母数字下划线，洛谷 UID 只认纯数字；
  写「阿杰」「阿杰的洛谷」这类，直接跳过，省一次注定失败的请求；
- 形状对但查不到的，也不报错：
  - AtCoder 会先问一次用户统计，发现这个号一条提交都没有，就提示「可能名字写错了」；
  - 洛谷返回 404，就说「洛谷上没有这个 UID」，不再把 HTTP 状态码端给用户看；
- 真抓到了就正常显示「AtCoder 12 题 / 洛谷 300 题」；
- 跳过的平台单独记在 `missed` 里（不再混进 `errors`），状态栏那句人话变成
  「…已加入；AtCoder 跳过：名字不像 AtCoder 账号，没去抓」这种，没有「失败」两个字。

加完还想补？成员卡片上右键「补抓平台数据」还在，随时能把账号补上重抓。

顺带修了一个加人时的坑：`normalizeAtcoderUser` 遇到中文名是直接抛异常的，原来那一句在 `try` 外面，
结果填中文 AtCoder 名字会让整个「加人」请求变成 400 —— 人根本加不进去。现在先看形状再规范化，
中文名走的是「跳过」分支。

全部成功加进队伍，提示里没有任何「失败」；原有 23 项接口回归测试全绿。
