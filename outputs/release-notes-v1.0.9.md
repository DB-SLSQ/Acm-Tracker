# ACM 训练台 v1.0.9

这一版只修一个 bug：**赛博主题下，点左侧菜单，被点中的那一条会变窄**。

### 下载

下载下方的 `ACM Trainer Setup 1.0.9.exe`，双击安装。装过旧版的直接覆盖，本地数据不会丢。
Windows 提示「已保护你的电脑」就点「更多信息」→「仍要运行」，个人项目没买数字签名，是正常情况。

---

### 修了什么

**现象**：只有赛博主题会犯。点左侧任何一个菜单项，那一条立刻变得很窄——不是宽度缩了，
是**整条被压扁**，高度从 41px 掉到 16px，文字被裁掉一截，只剩一个细条。
换回暗色 / 亮色 / 灰色 / 护眼，一切正常。

**原因**：赛博主题给「当前选中的菜单项」加了一道青光扫过的动画，为了不让扫光溢出去，
给菜单项设了 `overflow: hidden`。而菜单项本身是个 `<button>`，Chromium 对
「按钮 + flex 布局 + `overflow: hidden`」这个组合会把**内容高度算成 0**——
于是这一条只剩下下内边距的 16px，内容全被裁没了。

另外四个主题的菜单项没加 `overflow`，所以只有赛博主题中招。

**改法**：裁剪改用 `overflow: clip`。它同样能把扫光裁在圆角内，但不会创建滚动容器、
也不会把高度算错。视觉上完全没变，扫光该在哪还在哪。

顺带把这类问题加进了自动检查：现在会**逐个点一遍所有菜单项**，断言每一条高度一致且正常。
把 `overflow` 改回 `hidden` 反跑过一遍，确认这条检查真的会报错——不是摆样子。

---

### 说明

- 只有赛博主题受影响，其他四个主题本来就没这个问题。
- 菜单的功能一直正常（点得动、页面切得过去），坏的只是那一条的显示。
