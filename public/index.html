    成长

    每周做了多少题

    柱子 = 那一周首次通过的题数，柱子的颜色 = 当周平均难度（越亮越难）； 上面的小圆点 = 那周打的 rated 比赛，圆点旁的数字是这场涨跌多少分。

    每场比赛：赛前两周练了多少

    拿每场 rated 比赛往前推 14 天，看那段时间做了多少题、平均什么难度， 再和这场的涨跌分并排放在一起——练得多的时候是不是更稳，一眼能看出来。

    数据与隐私

    我的数据存在哪？会不会传到网上？

    全部存在本机：装好的程序在 %APPDATA%\acm-trainer\data\trainer.db， 网页版在项目的 data\trainer.db。不需要登录 Codeforces，也不要密码， 抓的都是公开数据。除了抓题库和赛程本身发出的请求，程序不往任何服务器发东西。

    换电脑、重装系统怎么带走进度？

    设置 → 数据安全：备份数据库存一份完整的库；导出训练数据把设置、勾选进度、 屏蔽表、虚拟赛记录、做题手感打成 JSON，换电脑导入即可。覆盖安装不会丢数据，卸载也不会删。

    抓不到数据

    Codeforces 一直转圈或者报超时

    国内直连 codeforces.com 经常超时，程序等 15 秒就会放弃并报错。挂上代理再点一次「重新加载」。 已经抓到的题库、提交记录、rating 曲线不会因为这次失败而丢，页面照常显示上次的数据。

    洛谷题库抓不动，提示 fetch failed

    洛谷的题目列表、比赛列表、练习页都有一道「cookie 挑战」：不带它当场下发的通行证就一直重定向， Node 的请求只会报一句 fetch failed，看着像断网。程序已经自动处理（接下 set-cookie 再请求一次），你不用做任何事。如果还是失败，多半是被对方风控拦了，等十几分钟再试。

    顺便说明：抓取不带你的账号身份（不登录、不用你的 cookie），单线程、请求间隔 1.2 秒， 一次最多 60 个请求，只按难度档抽页、不爬全库。

    AtCoder 的数据从哪来？要登录 AtCoder 吗？

    题目、难度、提交记录都来自 Kenkoooo 的 AtCoder Problems 公开接口；赛程来自它的 contests.json。全程不需要登录 AtCoder，也不会往对面提交任何东西。

    按钮点了没反应

    点「秒了 / 刚好 / 卡住 / 看题解」弹「接口不存在」

    这是 0.1.7 的毛病（撤掉背景图功能时误删了两个接口），0.1.8 已经修好，升级到最新版即可。 那段时间标不了手感，但之前标过的记录都还在。

    补题队列里全是我做过的题

    0.1.9 之前的 bug：一道题先失败、后来通过了，它只被记进「已通过」，没从「没过的题」里摘掉， 于是永远赖在队列里。升级后队列只剩真的没做出来的题。

    计划是怎么排的

    训练计划会自己变吗？做过的题会被换掉吗？

    不会。计划在你点「生成训练计划」的那一刻就钉住了：做过的题留在原位显示成已完成， 只有你改目标分、改每周题量、屏蔽某道题，或者自己点「重新生成」，才会重挑一遍。

    「落后几天」是怎么算的？为什么今天这张卡不显示落后？

    日程从「计划定下来的那天」开始排，落后天数只统计今天之前该做完的题。把今天算进去的话， 每天早上起来都会凭空落后一整天，那个数字就没意义了。

    每天那四档难度是什么意思？

    练手 / 进阶 / 提升 / 学习，四档间距 200 分，围着这一阶段的中心浮动（第一阶段中心＝你的水平 和目标的中值）。一天几题就顺着发：四题就每档一道，两题则轮着来，长期各档一样多。

    题单里为什么看不到算法标签？

    设置里开了「隐藏题目里的算法标签」。关了就能看见，还会给出「重点补强」是哪个方向。

    推题模型训练完为什么说「没赢过基线」？

    训练会按时间切出一段留出集，和「只看难度差」的老办法比。AUC 要不低于 0.75 并且明显优于基线才会启用，赢不了就继续用内置规则——这是故意的，宁可不用也不瞎猜。

    怎么知道有没有新版本？

    设置 → 数据安全 → 「检查更新」，它会去问 GitHub 上的最新版本号；页脚也一直写着当前版本。 下载链接永远指向最新版：github.com/DB-SLSQ/Acm-Tracker/releases/latest

    设置

    改动会自动保存，下次打开保持原样。

    界面模块

    不需要的模块可以直接关掉，连标题都不显示。

    今日卡片

    卡片上那个「今天补一个方向」的入口，不想用可以关掉——关掉之后今日卡片只剩当天计划里的题。

    数据安全

    题库和训练记录都在本机。这里可以一键备份数据库、导出/导入训练数据（换电脑时用）， 顺便检查有没有新版本。

    计划自检

    备份会存到数据目录的 backups 里，随时可以翻出来。

    列表密度

    题单太长的时候可以切紧凑一点，一次多看几行。

    水平评估

    算「你在这个专题上做到什么难度」时，忽略掉比当前 rating 低一段的题。 签到题人人都做、只是恰好带了这个标签，算进来会把你的水平整体拉低—— 比如做过的贪心题里大半是签到题，75 分位就会被拖到比你的实际水平低两三百分。

    填 0 表示不排除；默认 400。

    题单构成

    推荐题单里，同一个知识点标签最多占多少比例。调低会让题目更杂， 调高会更集中在几类题上——一份计划里同一个专题刷太多遍，别的方向就练不到了。

    默认 40%。填得越低，题目越杂。

    标签显示

    勾上以后，训练计划和训练日程里的题目都不显示算法标签（「重点补强」那行也会换成模糊说法）， 自己判断这道题该怎么做。适合不想被剧透的人。能力画像、做题记录这类分析页面不受影响。

    题目来源

    训练计划默认全用 Codeforces 的题。勾上以后按比例混进别的平台，各占四分之一、每天最多一道： AtCoder（ABC / ARC / AGC，来自 Kenkoooo 公开接口）和洛谷（要先在下面「洛谷」里抓一次题库）。 两个平台都不需要登录，也不会往对面提交任何东西；做过的题在同步过之后会自动排除、自动打勾。

    洛谷题进题单之前，先到下面「洛谷」那里抓一次题库（约 1 分钟）。

    用户名就是 atcoder.jp 个人主页地址里的那个，区分大小写。第一次同步会抓题库（ABC/ARC/AGC 里有难度的题）和你的全部提交记录；之后只补新的记录，题库 7 天才换一次。 做过的 AtCoder 题会自动排除、自动打勾。

    打卡提醒

    到点当天还有没打勾的题，就让系统弹一条通知。只在你开着程序的时候生效， 不联网、不发任何数据；做完了或者已经提醒过就不会再打扰。

    默认关闭。

    推题模型

    从已结束的 rated 比赛里学「以你现在的水平，能不能做出这道题」， 用这个概率来挑难度合适的题。数据只统计公开的比赛结果，不会提交任何东西。 训练要跑十几分钟，期间可以关掉设置面板，它会在后台继续。 模型只有在留出集上明显赢过「只看难度差」的基线时才会启用，否则继续用内置规则。
